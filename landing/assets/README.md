# Logos oficiales de MindLink

Los archivos suministrados por el equipo son la fuente visual oficial. No deben
redibujarse, recolorearse, retocarse ni sustituirse por SVG aproximados.

- `mindlink-email-logo.png`: archivo original completo, conservado como fuente.
- `../mindlink-logo-horizontal-transparent.png`: recorte transparente para la landing.
- `../mindlink-email-logo.png`: misma versión transparente para conservar la URL pública del correo.
- `../mindlink-logo-symbol-original.png`: isotipo original, usado en la vista visual principal.

La versión transparente solo elimina espacio cuya opacidad ya era cero en el
PNG original. Los píxeles visibles, proporciones, tipografía, degradados y
contornos permanecen intactos; no se redibujó ningún elemento.
